Load in Chrome

Developer mode installation — no build step needed

1
Open Chrome and navigate to chrome://extensions
2
Enable "Developer mode" (top-right toggle)
3
Click "Load unpacked" and select the pagelens/ directory
4
The PageLens icon appears in your toolbar — click it on any page to audit!
